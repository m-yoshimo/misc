## 実行のしかた

- 各コマンドは、「実行する行」を **一字一句そのまま** Bash ツールで実行してください（1 回の呼び出しで 1 行）。
  Bash ツールの `timeout` 引数は 600000 にしてください（行の中の `timeout {TIMEOUT}` が先に打ち切るので、待ちきれずに裏へ回ることはありません）。
  `run_in_background` は使わないでください。
- 引数を足したり変えたりしないでください。出力を途中で切らないでください（`| tail` / `| head` を付けない）。
- 終了コードが 124 のときは、`timeout {TIMEOUT}` で打ち切られたことを表します。そのまま報告してください（実行し直さない）。
- コマンドが失敗したら（終了コードが 0 以外）、残りのコマンドは実行せずに報告してください。
- ファイルを作成・編集・削除しないでください（出力の保存先へのログの書き出しを除く）。**失敗しても直さないでください。**
- git の変更系の操作（`add` / `commit` / `push` / `stash` / `restore` / `reset` / `checkout` / `clean` など）をしないでください。
