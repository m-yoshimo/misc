## 作業状態の都度報告

作業が完了したとき、または何かの結果を待っているときは、都度その状態を明示する。

**Why:** 作業が止まっているように見えるのを防ぐため。ユーザーは次に何が起きているかわからないと不安になる。

**How to apply:**
- 作業完了時: 「終わりました」と明示する
- 待機中（typecheck 実行中、ビルド待ち、ツール結果待ちなど）: 「〇〇の結果待ちです」と伝える
